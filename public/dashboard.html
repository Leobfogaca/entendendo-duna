Como interpretar os indicadores

O site calcula o personagem com base nas sete escolhas. Cada alternativa contribui com um ponto para um dos quatro perfis. Em caso de empate, vence o perfil escolhido mais recentemente entre os empatados.

Por enquanto, o painel mostra somente conclusões realizadas nesta sessão do navegador. Não é uma amostra real de visitantes e nenhum resultado foi enviado ao banco de dados.

Para registrar resultados de usuários diferentes, a próxima etapa será conectar cadastro, autenticação, API Node.js e MySQL. Nesta versão, não há cálculo de nota, acertos ou erros.
