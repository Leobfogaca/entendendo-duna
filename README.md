ENTENDENDO DUNA
O destino é escrito ou escolhido?
Entenda Duna antes e depois do filme.

O Entendendo Duna é um projeto individual desenvolvido na São Paulo Tech School (SPTech), durante o segundo semestre de 2026. A proposta é criar um website informativo e interativo sobre os filmes Duna (2021) e Duna: Parte Dois (2024), dirigidos por Denis Villeneuve.

O site busca ajudar quem ainda não assistiu aos filmes a conhecer esse universo sem spoilers e oferecer a quem já assistiu um espaço para explorar seus temas políticos, filosóficos e cinematográficos.

Objetivo -
Criar uma experiência acessível para conhecer e compreender melhor o universo dos dois filmes, com conteúdos organizados de acordo com o que cada visitante já assistiu.

Tecnologias -
- HTML: estrutura das páginas.
- CSS: identidade visual e responsividade.
- JavaScript: validações e interações.
- Node.js: API para integração entre o site e o banco de dados.
- MySQL: armazenamento de dados.
- Git e GitHub: versionamento e histórico de desenvolvimento.


Como executar -
Na fase inicial, as páginas HTML podem ser abertas localmente no navegador a partir da pasta public/. Quando a API e o banco de dados estiverem integrados, esta seção será atualizada com os comandos e os requisitos necessários para executar o sistema completo.
Documentação e desenvolvimento
A documentação acadêmica do projeto, o planejamento e o Diário de Prompts fazem parte do acompanhamento do desenvolvimento.  

Sobre o projeto -
O tema foi escolhido pelo interesse nos filmes de Denis Villeneuve e nas reflexões que a história apresenta sobre poder, destino, crenças e escolhas. Mais do que resumir a trama, a ideia é ajudar outros espectadores a explorar esses assuntos.
